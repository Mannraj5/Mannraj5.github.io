Project 02Academic project, extended for portfolio

Purple Team Lab: Exploitation and Detection Engineering

An isolated Kali Linux (attacker and sensor) versus Windows 7 (victim) lab, built to attack a system and then detect it.

Kali LinuxSnort 3MS17-010MITRE ATT&CKpytest
github.com/Mannraj5/Project-2-Purple-Team-Lab
  • Executed two attack chains in a self-owned, host-only lab: a user-execution dropper with privilege escalation, and an MS17-010 (EternalBlue-family) SMB exploit chain.
  • Created and tuned 6 custom Snort 3 signatures across reconnaissance, delivery, exploitation and command-and-control, and scored detection performance for every attack phase.
  • Traced two signatures that returned zero alerts to NIC offload behaviour at the capture point, where the sensor was inspecting only part of the traffic.
  • Showed that a port-based C2 rule missed the same payload on a different port, while a content-based rule caught it on both.
ResultReproducible methodology with an ATT&CK-mapped write-up, a research report, and a replay and scoring harness backed by pytest.
Project 06Academic project, extended for portfolio

Cloud Security Log Analysis

SQL detections over cloud identity, IAM and database-configuration logs, built to catch common cloud database attack paths.

SQLSQLiteMITRE ATT&CKIAM logsunittest
github.com/Mannraj5/Project-6-Cloud-Security-Log-Analysis
  • Generated 14 days of synthetic logs and planted three incidents: a brute-force chain ending in a public production database, a password spray, and encryption at rest disabled.
  • Wrote 3 triggers and 5 batch queries mapped to MITRE ATT&CK, using SQLite.
  • Found that a successful password spray is missed by per-account rules and caught by correlating sign-in failures and successes on source IP.
  • Wrote a research report on securing Database-as-a-Service, using the Capital One, Snowflake-customer and Midnight Blizzard incidents as case studies.
ResultAll 9 expected alerts fired, no alerts on benign activity, and 12 of 12 tests passed.
Project 07Portfolio project

PCAP Threat Analyzer (pcapscope)

A packet-capture analyser using only the standard library. Reads pcap and pcapng files and decodes Ethernet, IPv4/IPv6, ARP, TCP, UDP, ICMP, DNS and SMB.

pcap / pcapngDNSSMBGitHub Actionspytest
github.com/Mannraj5/Project-7-PCAP-Threat-Analyzer
  • Eight detectors run in a single pass: port scan, host sweep, C2, beaconing, SMB exploit, DNS tunnelling, ARP spoofing and cleartext credentials. A capture-health check is included.
  • Found and fixed a session-tracking bug (sessions keyed on three fields instead of the full 4-tuple) and added a regression test.
  • 59 synthetic-capture tests, with GitHub Actions CI on Ubuntu and Windows.
ResultValidated against six captures from the Purple Team Lab. Packet counts matched capinfos, expected attacks were detected, the baseline was clean, and a 132,727-packet scan was analysed in 2.4 s.

Project 03Academic, extended

Network Protocols Lab: DNS, QUIC/HTTP3 and ICMP

A packet-level investigation of three internet protocols using custom tools and Wireshark captures.

WiresharkDNSQUICICMPraw sockets
